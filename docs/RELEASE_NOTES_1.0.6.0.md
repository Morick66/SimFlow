# SimFlow 1.0.6.0 发布说明

SimFlow 1.0.6.0 是首个公开提供 Windows 二进制下载的版本。

## 下载

- `SimFlow-1.0.6.0-win-x64-portable.zip`：Windows 10 2004+ / Windows 11 x64 免安装便携版；
- `SHA256SUMS.txt`：下载包的 SHA-256 校验值。

请只从本仓库的 GitHub Releases 页面下载，并在运行前核对 SHA-256。完整解压 ZIP 后运行 `SimFlow.exe`，不要直接在压缩包内启动。

## 关于 Windows 安全提示

当前便携版没有商业代码签名。Windows 首次运行时可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。确认下载来源和 SHA-256 后，可以选择“更多信息”→“仍要运行”。本版本不需要安装任何证书。

## 主要内容

- 项目、状态、版本、标签、存储位置和历史记录管理；
- SHA-256 校验的项目迁移与失败恢复；
- 删除项目或版本时移入 `.simflow-recovery`；
- 离线存储保护、冲突扫描隔离和迁移源保留；
- 统计分析、仿真报告模板和快捷入口。

## 数据位置

配置、数据库和日志位于 `%LOCALAPPDATA%\SimFlow`，项目文件位于用户配置的 Work 目录，都不在便携版程序目录内。升级时建议把新版本解压到新目录，不要覆盖正在运行的旧目录。

## 已知限制

- 当前只提供 Windows x64 构建；
- 尚未使用商业代码签名，SmartScreen 信誉需要随下载量逐步建立；
- 首发版不会自动永久删除迁移后的源副本；
- 真实 SMB 性能取决于网络、权限和服务器实现。
