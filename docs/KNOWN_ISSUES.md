# SimFlow 1.0.5 已知问题

- 首发版不会自动永久删除迁移后的源副本。目标成为主副本后，旧源会保留，需人工核对和清理。
- `.simflow-recovery` 中的项目或版本不会被扫描器重新导入；恢复操作目前需要人工完成。
- 当前没有官方公开二进制；个人身份自签的旧安装包已撤回，等待使用中性发布身份重新签名。
- 当前仅提供 x64 构建。
- 真实 SMB 的性能取决于网络、权限和服务器实现。迁移前应停止 CAE 求解器写入项目目录。
- `docs/simflow-ui.png` 是历史截图；当前界面仍需在目标 Windows 的缩放、深浅主题和键盘环境下验收。
- 软件仅作为项目标签和统计维度，SimFlow 1.0.5 不负责启动 CAE 软件。
