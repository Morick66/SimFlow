# SimFlow 1.0.10.0 发布说明

本版改善项目筛选体验，并修复软件标签改名后项目数据未同步的问题。

## 下载和升级

- `SimFlow-1.0.10.0-win-x64-portable.zip`：Windows 10 2004+ / Windows 11 x64 免安装便携版；
- `SHA256SUMS.txt`：下载包的 SHA-256 校验值。

请从本仓库的 GitHub Releases 下载两个文件并核对哈希。关闭旧版后，将 ZIP 完整解压到新目录运行 `SimFlow.exe`；不要覆盖正在运行的旧目录。升级前建议备份 `%LOCALAPPDATA%\SimFlow` 和项目 Work 目录。回滚与卸载方式见 [安装、升级与卸载](INSTALLATION.md)。

## 更新内容

- 重新整理“所有项目”筛选区：状态与需求人、仿真类型、标签、使用软件等条件分组显示；收藏改为可与其他条件叠加的“仅看收藏”开关，并提供清除筛选入口。
- 移除功能重复的独立“收藏”侧栏页面；首页收藏统计入口仍可直达已筛选的项目列表。
- 更改软件标签名称时，同步更新已有项目的软件记录；旧名称不再作为新项目或编辑项目的候选项重复出现。
- 对此前版本已改名但仍残留在项目中的旧软件标签，可在设置的“软件标签”中使用“合并旧标签…”将其并入当前标签。

## 范围与验收状态

软件标签改名会同步本地数据库中的项目关联，并尝试更新项目目录中的 `project.json`。存储位置离线或文件写入失败时，项目元数据进入后续同步队列；请在存储恢复后检查相应项目。历史旧标签的合并需要用户明确选择旧名和目标新名，不会自动猜测映射。

发布前 Windows CI 已通过自动化测试、依赖漏洞检查和便携版构建。实际 Windows 界面效果、旧数据升级以及真实项目目录/SMB 场景尚待实机验收；构建通过不代表这些场景已验证。

## Windows 安全提示

当前便携版没有商业代码签名，首次运行可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。请先确认下载来源和 SHA-256；本版不需要安装证书。
