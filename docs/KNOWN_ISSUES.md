# SimFlow 1.0.8 已知问题

- 归档自动删除源目录前会再次校验；如果 Adams、求解器或其他程序占用文件，归档目标仍保持为主副本，源目录进入待清理状态。
- `.simflow-recovery` 中的项目或版本不会被扫描器重新导入；恢复操作目前需要人工完成。
- GitHub 便携版尚未使用商业代码签名，Windows 首次运行可能显示“未知发布者”或 SmartScreen 提示。请只从官方 Releases 下载并核对 SHA-256。
- 当前仅提供 x64 构建。
- 真实 SMB 的性能取决于网络、权限和服务器实现。迁移前应停止 CAE 求解器写入项目目录。
- `docs/simflow-ui.png` 是历史截图；当前界面仍需在目标 Windows 的缩放、深浅主题和键盘环境下验收。
- 软件仅作为项目标签和统计维度，SimFlow 1.0.8 不负责启动 CAE 软件。
