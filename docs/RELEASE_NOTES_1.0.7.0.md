# SimFlow 1.0.7.0 发布说明

SimFlow 1.0.7.0 修正了归档语义：归档成功后默认删除原 Work 目录，不再长期保留两份项目。

## 下载

- `SimFlow-1.0.7.0-win-x64-portable.zip`：Windows 10 2004+ / Windows 11 x64 免安装便携版；
- `SHA256SUMS.txt`：下载包的 SHA-256 校验值。

请只从本仓库的 GitHub Releases 页面下载，并在运行前核对 SHA-256。完整解压 ZIP 后运行 `SimFlow.exe`。

## 归档行为

- 默认开启“归档成功后删除源目录”；
- 归档副本经过复制、SHA-256 校验、再次源目标比对并切换为主副本后，才会删除原 Work 目录；
- 可以在“设置 → 项目目录 → 工作站 Archive”关闭自动删除，继续保留源副本；
- 文件被占用、源文件变化或删除失败时，已归档目标仍是主副本，原目录保留并进入待清理状态；
- 在“迁移恢复”中可以重新校验并删除待清理的源目录。

归档前请保存并关闭 Adams/View、求解器和可能持续写入项目文件的其他程序。

## 关于 Windows 安全提示

当前便携版没有商业代码签名。Windows 首次运行时可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。确认下载来源和 SHA-256 后，可以选择“更多信息”→“仍要运行”。本版本不需要安装任何证书。
