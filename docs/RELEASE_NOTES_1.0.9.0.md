# SimFlow 1.0.9.0 发布说明

本版完善项目查找与恢复入口，并修正几处界面布局。

## 下载和升级

- `SimFlow-1.0.9.0-win-x64-portable.zip`：Windows 10 2004+ / Windows 11 x64 免安装便携版；
- `SHA256SUMS.txt`：下载包的 SHA-256 校验值。

请从本仓库的 GitHub Releases 下载两个文件并核对哈希。关闭旧版后，将 ZIP 完整解压到新目录运行 `SimFlow.exe`；不要覆盖正在运行的旧目录。升级前建议备份 `%LOCALAPPDATA%\SimFlow` 和项目 Work 目录。回滚与卸载方式见 [安装、升级与卸载](INSTALLATION.md)。

## 更新内容

- “所有项目”新增需求人、仿真类型、标签和使用软件筛选，可与状态、搜索和排序组合使用；
- 新建/编辑项目时，已选标签和候选标签改为多行自适应排列；
- 修复统计分析顶部状态卡片文字被遮挡，并缩小首页状态卡片周围的过宽留白；
- 新增基础项目回收站：查看正常删除后移入恢复区的项目，恢复到原位置，或经二次确认后彻底删除。恢复时会拒绝覆盖已有目录或冲突编号。

## 范围与验收状态

回收站仅覆盖正常删除后移入 `.simflow-recovery/Projects` 的项目；版本恢复、迁移中断恢复和恢复到新位置尚不在本版范围。彻底删除不可撤销，请先用测试项目确认流程。

发布前的 Windows CI 已通过 98 项自动化测试、依赖漏洞检查与便携版构建。实际 Windows 界面显示、旧版升级、真实 SMB 和项目目录恢复操作尚未完成实机验收；构建通过不代表这些场景已经验证。

## Windows 安全提示

当前便携版没有商业代码签名，首次运行可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。请先确认下载来源和 SHA-256；本版不需要安装证书。
