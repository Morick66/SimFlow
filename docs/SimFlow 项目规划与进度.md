## 2. V1.0 功能范围

### 已实现

- 项目创建、编辑、删除记录、搜索、筛选和收藏；
- 未开始、进行中、等待中、已完成状态及状态历史；
- 项目版本、备注、标签、软件标签、封面和仿真类型；
- 首页四列看板、项目列表、详情和统计页；
- 仿真报告模板与 Delivery 报告快捷入口；
- 本机 Work、工作站 Work、工作站 Archive；
- 扫描恢复、数据库/项目档案冲突确认；
- 暂存复制、SHA-256 校验、迁移恢复和目标冲突保护；
- 签名 x64 MSIX 侧载交付。

### 明确不包含

- 多人账户、权限和审批；
- Web 服务或实时双向同步；
- CAE 求解控制和结果可信性判断；
- CAE 软件启动器；
- 自动永久删除迁移源副本；
- x86、ARM64 和 macOS 版本。

## 3. 数据安全基线

1. 项目目录使用 ASCII 编号，显示名称与物理路径分离。
2. SQLite 是全局索引，每个项目携带独立 `project.json`。
3. 项目和版本的文件删除改为移动到 `.simflow-recovery`；数据库失败时恢复原目录。
4. 迁移使用暂存目录，验证成功后才提升目标并切换数据库位置。
5. 提升前重新比对当前源目录，复制期间发生写入会停止迁移。
6. 迁移重试必须验证源、目标项目身份和文件内容。
7. 首发版保留迁移源副本，不由应用执行永久删除。
8. 冲突副本在用户选择前不参与正式项目的版本对账。
9. 存储位置离线时禁止状态修改，避免数据库与项目档案不一致。
10. 配置使用副本提交，保存失败不改变当前内存配置。

## 6. 已知限制

- 自动迁移源清理已禁用；源副本由用户人工核对和处理。
- `.simflow-recovery` 暂无应用内恢复界面。
- 自签 MSIX 需要预先信任发布证书。
- 当前截图不是 1.0.5 最终发布截图。
- 真实 SMB、显示缩放、深浅主题和键盘操作仍需在目标 Windows 上做最终冒烟。
