# SimFlow 1.0.5.0 发布说明与验证记录

> 撤回说明：该版本原公开二进制使用了不适合公开分发的个人身份自签证书，现已从 GitHub Release 撤下。本文件保留源码和验证记录，不再代表存在可下载的官方安装包。

发布日期：2026-09-23

## 发布定位

这是 SimFlow 首个完成系统验证的源码里程碑。公开二进制将在使用中性发布身份和合适的签名渠道后重新发布。

## 关键修复

- 项目和版本删除改为移动到 `.simflow-recovery`，数据库提交失败时恢复原目录。
- 迁移提升前重新校验当前源目录，拒绝源文件在复制期间发生变化的结果。
- 迁移重试验证项目身份、来源和目标，拒绝接管任意既有目录。
- 冲突副本不再向正式项目注入版本记录。
- 离线项目禁止状态修改，避免数据库与项目档案不一致。
- 设置保存采用副本提交，写盘失败不会污染当前内存配置。
- 首发版禁用迁移源目录自动永久清理。

## 已完成验证

- 干净 Git 检出的发布代码通过锁定依赖还原；精确提交见随包提供的 `RELEASE_INFO.txt`。
- Windows Release x64 编译：0 警告、0 错误。
- 自动化测试：92/92 通过。
- NuGet 直接与传递依赖漏洞扫描：未发现已知漏洞。
- 签名 MSIX：`Get-AuthenticodeSignature` 返回 `Valid`。
- 1.0.4.0 到 1.0.5.0 升级后，配置、数据库及 74 个项目目录保持不变。
- 卸载 1.0.5.0 后，包外配置、数据库及项目目录保持不变。
- 使用正式包重装后，版本为 1.0.5.0、包状态为 `Ok`，数据哈希和项目数量保持不变。
- 重装后完成一次真实进程启动，最新日志未出现新的 Fatal 或 Unhandled 错误。

最终发布提交、安装包哈希以随发布包提供的 `RELEASE_INFO.txt` 和 `SHA256SUMS.txt` 为准。

## 已知限制与未完成的人工验收

- 验证机缺少 `mspdbcmf.exe`，因此不生成符号包；MSIX 构建和签名成功。
- 当前包仅提供 x64，不提供 x86 或 ARM64。
- 自签证书适用于受控侧载，不等同于 Microsoft Store 或受信任商业证书分发。
- 100%、125%、150% 缩放、浅色/深色主题和完整交互流程仍需人工视觉冒烟。
- 自动化测试覆盖本地临时目录；真实 SMB 共享上的断网、占用文件和求解器运行中迁移仍需在专用测试项目上人工验收。
- 迁移成功后源副本不会自动永久删除，需要人工确认后清理。
